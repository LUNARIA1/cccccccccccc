CBS란 무엇인가?

CBS (Curly Brace Syntax)는 RisuAI에서 사용하는 템플릿 변수 치환 시스템입니다. {{변수명}} 형식의 중괄호 구문을 사용하여 동적으로 텍스트를 치환하고 조작할 수 있습니다.

기본 예시

{{char}}가 {{user}}에게 말했다: "안녕하세요!"

위 코드는 실행 시:

Alice가 John에게 말했다: "안녕하세요!"

로 변환됩니다 (캐릭터 이름이 Alice, 사용자 이름이 John일 경우).

기본 문법

1. 단순 변수

{{변수명}}

2. 인자가 있는 함수

{{함수명::인자1::인자2::인자3}}
  • 인자는 ::(더블 콜론)으로 구분합니다
  • 일부 함수는 가변 인자를 지원합니다

3. 조건문

{{#when 조건}}
  조건이 참일 때 표시될 내용
{{:else}}
  조건이 거짓일 때 표시될 내용
{{/when}}

#when 조건문 연산자

{{#when}}은 RisuAI에서 가장 강력한 조건문 기능입니다.

기본 사용법

{{#when 조건}}
  조건이 참일 때
{{:else}}
  조건이 거짓일 때
{{/when}}

비교 연산자

  • ::is:: - 같음 (==)
  • ::isnot:: - 다름 (!=)
  • ::>:: - 크다 (>)
  • ::<:: - 작다 (<)
  • ::>=:: - 크거나 같다 (>=)
  • ::<=:: - 작거나 같다 (<=)

논리 연산자

  • ::and:: - AND
  • ::or:: - OR
  • ::not:: - NOT

고급 연산자

  • ::keep:: - 공백 유지
  • ::legacy:: - 레거시 공백 처리
  • ::var:: - 변수가 truthy인지 확인
  • ::toggle:: - 토글 활성화 확인

예시

{{#when::{{getvar::score}}::>::50}}
  점수가 50 이상입니다!
{{:else}}
  점수가 50 미만입니다.
{{/when}}

  관리자이고 탈옥이 활성화됨
{{/when}}

주의사항 및 팁

⚠️ 주의사항

  1. 인자 구분자: 함수 인자는 반드시 ::(더블 콜론)로 구분해야 합니다. ;(세미콜론)이나 :(단일 콜론)은 작동하지 않습니다.

  2. 특수문자 이스케이프: CBS 내에서 특수문자를 표시하려면 이스케이프 함수를 사용하세요:

    {{bo}}char{{bc}} → {{char}} (실제 표시)

  3. 변수 실행 모드: {{setvar}}, {{addvar}} 등은 runVar 모드일 때만 실행됩니다. 일부 컨텍스트에서는 작동하지 않을 수 있습니다.

  4. 배열/객체 형식: 배열과 객체는 반드시 올바른 JSON 형식이어야 합니다:

    올바름: ["a","b","c"]
잘못됨: ['a','b','c']

  5. 조건문 공백: {{#when}} 블록 내에서 공백이 자동으로 제거될 수 있습니다. 공백을 유지하려면 ::keep:: 연산자를 사용하세요.

💡 팁

  1. 디버깅: 변수 값을 확인하려면 그냥 출력해보세요:

    디버그: 현재 counter = {{getvar::counter}}

  2. 조건문 중첩: 복잡한 로직에는 조건문을 중첩할 수 있습니다.

  3. pick vs random: 일관된 결과가 필요하면 {{pick}}을, 매번 다른 결과가 필요하면 {{random}}을 사용하세요.

  4. 메타데이터 활용: {{metadata}}로 다양한 시스템 정보를 확인할 수 있습니다:

    {{metadata::imateapot}} → 🫖

  5. 성능: 복잡한 CBS는 성능에 영향을 줄 수 있습니다. 필요한 경우에만 사용하세요.
