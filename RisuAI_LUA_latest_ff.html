📌 1. 개요

RisuAI의 Lua 스크립팅 시스템을 사용하면 캐릭터와 모듈에 대한 동적 동작을 생성할 수 있습니다. Lua 스크립트는 채팅 조작, LLM 상호 작용 등을 위한 포괄적인 API에 접근할 수 있는 샌드박스 환경에서 실행됩니다.

스크립트 유형

  • 트리거 스크립트: 이벤트에서 실행되는 캐릭터별 스크립트
  • 모듈 스크립트: 모든 채팅에서 실행되는 전역 스크립트
  • 편집 트리거: 입력/출력/표시 데이터를 수정하는 스크립트

보안 모델

접근 수준 설명
안전 접근 (Safe Access) 기본 채팅 및 변수 작업
편집 표시 접근 (Edit Display Access) 표시 출력을 수정할 수 있음
저수준 접근 (Low Level Access) 고급 기능(LLM, 이미지 생성, 네트워크 요청)에 대한 전체 접근

🚀 2. 시작하기

기본 스크립트 구조

-- 다양한 트리거에 대한 이벤트 핸들러 정의
function onStart(id)
    -- 채팅 시작 시 실행
    log("채팅이 시작되었습니다!")
end

function onInput(id)
    -- 사용자가 입력을 보낼 때 실행
    log("사용자 입력을 받았습니다")
end

function onOutput(id)
    -- AI가 출력을 생성한 후 실행
    log("AI 출력이 생성되었습니다")
end

편집 리스너

-- 다양한 편집 이벤트 리스닝
listenEdit('editInput', function(id, data, meta)
    -- 처리 전 사용자 입력 수정
    return data
end)

listenEdit('editOutput', function(id, data, meta)
    -- 표시 전 AI 출력 수정
    return data
end)

listenEdit('editDisplay', function(id, data, meta)
    -- 최종 표시 출력 수정
    return data
end)

listenEdit('editRequest', function(id, data, meta)
    -- LLM에 대한 요청 수정 (data는 OpenAIChat[] 배열)
    return data
end)

📡 3. 이벤트 핸들러

핸들러 설명 파라미터
onStart(id) 채팅 시작 시 트리거됨 id: 접근 키
onInput(id) 사용자 입력 시 트리거됨 id: 접근 키
onOutput(id) AI 출력 후 트리거됨 id: 접근 키
onButtonClick(id, data) 버튼 클릭 시 트리거됨 id: 접근 키, data: 버튼 데이터

⚙️ 4. 코어 API 함수

로깅

log(value)

브라우저 콘솔에 데이터를 출력합니다.

CBS (중괄호 구문) 파서

result = cbs(value)

문자열에서 중괄호 구문을 파싱합니다 (예: {{char}}, {{user}}).

local msg = cbs("안녕하세요 {{user}}, 저는 {{char}}입니다")
log(msg) -- "안녕하세요 홍길동, 저는 앨리스입니다"

💬 5. 채팅 관리

함수 설명 사용 예시
getChat(id, index) 인덱스로 특정 채팅 메시지 가져오기 getChat(id, -1) → 마지막 메시지
getFullChat(id) 모든 채팅 메시지 가져오기 getFullChat(id)
setChat(id, index, value) 특정 채팅 메시지 수정 setChat(id, -1, "수정됨")
setChatRole(id, index, role) 특정 메시지의 역할 변경 setChatRole(id, -1, 'user')
setFullChat(id, messages) 전체 채팅 기록 대체 setFullChat(id, newChat)
addChat(id, role, value) 채팅에 새 메시지 추가 addChat(id, 'char', '메시지')
insertChat(id, index, role, value) 특정 위치에 메시지 삽입 insertChat(id, 0, 'system', '...')
removeChat(id, index) 특정 메시지 삭제 removeChat(id, -1)
cutChat(id, start, end) 지정 범위만 유지 cutChat(id, 0, 10)
getChatLength(id) 메시지 수 가져오기 getChatLength(id)
getCharacterLastMessage(id) 캐릭터 마지막 메시지 getCharacterLastMessage(id)
getUserLastMessage(id) 사용자 마지막 메시지 getUserLastMessage(id)

🤖 8. LLM 통합

간단한 LLM 호출

result = simpleLLM(id, prompt):await()

파라미터: id (접근 키, 저수준 접근 필요), prompt (텍스트 프롬프트)
반환값: {success: boolean, result: string}

고급 LLM 호출

result = LLM(id, messages, useMultimodal):await()
local messages = {
    {role = 'system', content = '당신은 유용한 어시스턴트입니다'},
    {role = 'user', content = '농담을 해주세요'}
}

local result = LLM(id, messages):await()
if result.success then
    log("LLM 답변: " .. result.result)
end

보조 LLM 호출

result = axLLM(id, messages, useMultimodal):await()

보조 LLM 호출 ('model' 대신 'otherAx' 모델 사용)

✅ 14. 모범 사례

1. 비동기 함수에는 항상 Await 사용

-- 잘못됨
local result = LLM(id, messages)

-- 올바름
local result = LLM(id, messages):await()

2. 오류 처리

local success, error = pcall(function()
    local result = simpleLLM(id, "테스트"):await()
    if not result.success then
        alertError(id, "LLM 오류: " .. result.result)
    end
end)

3. 복잡한 데이터에는 State 사용

setState(id, 'config', {enabled = true, maxLength = 100})
local config = getState(id, 'config')

📝 15. 예시 스크립트

메시지 카운터

function onOutput(id)
    local count = getChatVar(id, 'messageCount')
    if count == "" then count = "0" end
    count = tonumber(count) + 1
    setChatVar(id, 'messageCount', tostring(count))
    if count % 10 == 0 then
        alertNormal(id, count .. "개의 메시지를 보냈습니다!")
    end
end

자동 요약

function onOutput(id)
    local chatLength = getChatLength(id)
    if chatLength % 20 == 0 then
        local result = simpleLLM(id, "대화를 요약해주세요"):await()
        if result.success then
            setState(id, 'lastSummary', {summary = result.result})
            alertNormal(id, "채팅이 요약되었습니다!")
        end
    end
end

  • ✅ 상태 유지 동작
  • ✅ UI 상호 작용

  • ✅ 이미지 생성
  • ✅ 로어북 관리

기억하세요:

  • 비동기 함수에는 :await() 사용
  • pcall로 오류 처리
  • 복잡한 데이터에는 setState 사용
  • 접근 요구 사항 확인 (Safe/Low Level)
